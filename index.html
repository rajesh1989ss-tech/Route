Install

Served over https, Rhumb installs as a real app. In Chrome use the menu → Install app (or Add to Home screen), or the ⤓ Install button in the top bar. Once installed it opens full-screen and works with no signal — the chart, the code and the icons are all held on the device.

Keyboard

+ − zoom · F fit passage · M measure · U undo a leg · C centre on ship · L log a fix · K calculator · S sun · T theme · Esc close

Notes

The chart is a vector coastline held inside this file — it needs no internet and no chart licence. It is a planning and situational-awareness aid only. It is not an ECDIS, it carries no official charts, no depths and no navigational warnings, and it must never be used for navigation or to replace the approved passage plan.

Browsers only release GPS to pages served over https (or localhost). Opened straight off a phone's file system, the GPS button will be refused — host it and it works.
